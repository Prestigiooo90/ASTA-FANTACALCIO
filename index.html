1. Nome dell'asta

Un'etichetta per riconoscerla. Puoi crearne altre in seguito.

2. Squadre e crediti

Almeno 2 squadre. Ognuna avrà 3 P / 8 D / 8 C / 6 A da riempire con i crediti che scegli.

Il minimo teorico è 25 (1 credito per slot). Il classico è 500.

3. Nomi squadre

Puoi anche lasciare i nomi di default e cambiarli dopo.

4. Lista giocatori

Carica il file Excel delle quotazioni di Fantacalcio.it. Uso la colonna Qt.A per ordinare.

Le mie aste

Puoi tenere più aste in parallelo. Ognuna ha squadre, crediti e giocatori indipendenti. Modifica il nome direttamente qui.

Nomi squadre dell'asta corrente

Le modifiche si salvano automaticamente.

Salvataggio

Tutti i dati sono nel browser. Esporta un JSON per fare un backup o per spostare l'asta su un altro dispositivo.

L'export contiene tutte le aste. L'import può sostituire tutto o aggiungere le aste importate.

Ricarica giocatori dell'asta corrente

Sostituisci il file delle quotazioni (i giocatori già assegnati restano nelle squadre).

Statistiche giocatori (opzionale)

Carica i file Statistiche di Fantacalcio.it (stagione in corso e/o precedente). Aggiungo fantamedia, gol, assist e % titolarità a ogni giocatore, con ordinamento e consigli. Puoi selezionare entrambi i file insieme.

Prezzi & popolarità d'asta (opzionale)

Carica il CSV "i più comprati" (fantacalcio-online). Aggiunge il prezzo medio d'asta reale e la % di squadre che comprano ogni giocatore: il consiglio di spesa userà il prezzo di mercato, mostrerà l'appetibilità e ridimensionerà il piano rosa.

Zona pericolo

Reset totale: cancella tutte le aste, tutti i dati. Non si può annullare.
