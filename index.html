⚽ Asta Fantacalcio

1. Numero di squadre

Da 2 a 10 squadre. Ognuna partirà con 500 crediti e 3 P / 8 D / 8 C / 6 A da riempire.

2. Nomi squadre

Puoi anche lasciare i nomi di default e cambiarli più tardi da Impostazioni.

3. Lista giocatori

Carica il file Excel delle quotazioni di Fantacalcio.it (Quotazioni-Fantacalcio-Stagione-XXXX-XX.xlsx). Uso la colonna Qt.A per ordinare.

Nomi squadre

Modifica il nome delle squadre. Le modifiche si salvano automaticamente.

Salvataggio

Tutti i dati sono salvati nel browser. Esporta il file JSON di backup se vuoi tenere una copia o passare l'asta su un altro dispositivo.

Ricarica giocatori

Sostituisci il file delle quotazioni (i giocatori già assegnati restano nelle squadre).

Zona pericolo

Reset totale: cancella squadre, giocatori assegnati e budget. Non si può annullare.
